Seus dados e backup · v3.2

Importante: os dados são salvos neste dispositivo. Exporte um backup JSON após atualizar seus lançamentos e guarde-o em um local seguro. Instalar o aplicativo não sincroniza os dados entre aparelhos.

🔐 Criar novo backup protegido por senha

Crie uma senha forte e guarde-a: sem ela não será possível recuperar o backup criptografado. O arquivo será salvo somente onde você escolher. Seus lançamentos continuam armazenados localmente neste aparelho, sem criptografia no armazenamento do navegador.

* Saldo em caixa = receitas marcadas como recebidas − despesas marcadas como pagas, considerando as datas de pagamento/recebimento dentro do mês. Saldo previsto = saldo positivo acumulado dos meses anteriores + receitas do mês − despesas do mês, inclusive pendentes. O saldo negativo não é transferido. O saldo em caixa inclui o saldo positivo efetivamente acumulado dos meses anteriores, mais receitas recebidas no mês, menos despesas pagas no mês. Ao marcar uma despesa como paga, ela é descontada do caixa pela data efetiva do pagamento. O saldo negativo não é transferido para o próximo mês. Os lançamentos são armazenados apenas neste navegador/dispositivo (localStorage). Faça backups regulares: limpar dados do navegador pode apagar seu controle. O aplicativo funciona offline após salvar este arquivo, mas não sincroniza automaticamente entre dispositivos.
